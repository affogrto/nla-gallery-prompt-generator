# NLA Gallery Prompt Generator

NLA Gallery向けのランダムプロンプト生成器です。

## 使い方

1. `index.html` をブラウザで開く
2. `ランダム生成` を押す
3. 必要なら各項目の `固定` をオンにする
4. `コピー` で生成プロンプトをコピーする

## 仕組み

- キャラクター、衣装、表情・視線、ポーズ、象徴モチーフを候補リストからランダム選択します。
- 象徴モチーフは必ず1つだけ入ります。
- 出力プロンプトはDisplay First Design版です。L判・2L判・A4プリント、光沢写真紙、額装展示を想定します。
- Negative Prompt側にも印刷で潰れやすい細密背景、端切れ、情報過密を抑える指定を入れます。
- 候補リストは画面内で編集でき、ブラウザのlocalStorageへ保存されます。
