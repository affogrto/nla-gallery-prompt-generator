# NLA Gallery Prompt Generator

NLA Gallery向けの作品生成システムです。
固定世界観を保ったまま、カテゴリ化されたテーマ素材から展示用プロンプトを生成します。

## 使い方

1. `index.html` をブラウザで開く
2. `ランダム生成` を押す
3. 必要なら各項目の `固定` をオンにする
4. `コピー` で生成プロンプトをコピーする

## 仕組み

- 固定世界観として、NLA Gallery、セラフィナ、印刷品質、額装展示、余白、光、クリーン仕上げを保持します。
- テーマジェネレーターとして、今日のテーマ、カテゴリ、象徴モチーフ、衣装、視線、ポーズ、背景、演出、Signature Hook、Visual Surpriseをランダム選択します。
- カテゴリは `Flower × Memory × Water` のように管理します。
- 象徴モチーフはカテゴリの先頭要素に合わせて選ばれます。
- 出力では、画面上の象徴モチーフを必ず1つだけに制限します。
- Negative Prompt側にも、象徴の重複、説明的な小物、印刷で潰れやすい細密背景、端切れ、情報過密を抑える指定を入れます。
- 候補リストは画面内で編集でき、ブラウザのlocalStorageへ保存されます。
